# Lyn Météo

Lyn Météo is a free-for-life mobile app for clear, customizable, ad-free weather forecasts. Hourly forecasts for every commune in France, interactive graphs, favorites, light or dark theme.

- **[Website](https://www.lyn-meteo.fr/)**

## 🛠️ Tech Stack

- **[React Native](https://reactnative.dev)** - Native apps for Android, iOS, and more using React
- **[Expo](https://expo.dev/)** - Ecosystem of tools for React Native
- **[NestJS](https://nestjs.com/)** - Backend API framework
- **Python** - Weather data processing and calculations
- **[Bun](https://bun.sh/)** - Bridge used for the nightly batch processing
- **Meteo France API** - AROME and ARPEGE forecast models
- **[ECMWF](https://www.ecmwf.int/)** - European medium-range forecast data
